# Contributing

Thanks for helping Kepler 1.1 stay open and clean.

**Built by Aly Maknojiya** — community contributions welcome.

## Ways to help

- Improve docs and plain-language explanations  
- Add eval cases with reproducible steps  
- Propose training data that is clearly licensed for open use  
- Fix website accessibility and mobile layout  

## Rules

1. Be kind.  
2. Do not submit TypeSafe/Jev proprietary material.  
3. Do not remove attribution to Laya / ConvAI Innovations or Kyros Labs / Aly Maknojiya.  
4. Prefer small pull requests with a clear “why.”  

## Development (website)

```bash
npm install
npm run dev
npm run lint
npm run build
```
